# Krypto 1.0.0

The original Four Paws artwork, published as canonical v1.

- Nine animation states and 57 action frames.
- Sixteen clockwise look directions.
- Desktop Codex package and ChatGPT-compatible sprite sheets.
- Public ChatGPT adoption link.
- Individual GIFs, PNG frames and editable indexed frames.
- Portable installer and a phone-friendly animation gallery.

No face-contrast or motion-polish proposals are included. The desktop WebP is byte-identical to the canonical original. The full ChatGPT sheet has the same 73 drawings; only an unused desktop neutral-reference slot is transparent. The legacy ChatGPT sheet retains all 57 action drawings.
